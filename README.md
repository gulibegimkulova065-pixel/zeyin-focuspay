# ☂️ ZEYIN — Focus, AI Planner & Rewards

## 📌 Описание
ZEYIN решает проблему отвлекаемости студентов и низкой вовлеченности в рекламу у брендов. 
* **Пользователи** зарабатывают бонусы за продуктивное время (1 мин = 12 ₸).
* **Бренды** получают гарантию внимания аудитории через интерактивные квизы после сессий.

## 🚀 Функции
- **Фокус-сессии:** защита от переключения вкладок (анти-чит).
- **ZEYIN AI Planner:** автоматически разбивает любую тему на пошаговый план.
- **Аркадные игры:** мини-игры («Змейка», «Кликер») для отдыха.
- **Партнерские квизы:** закрепление рекламы и получение наград.
- **Мультиязычность:** KZ
